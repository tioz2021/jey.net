# UI-система

Правила, чтобы новые экраны не расходились по форме и размеру.

## Токены

```text
--control-h: 40px       обычные контролы
--control-h-sm: 32px    компактные иконки, верхняя панель
--radius-sm: 7px
--radius-md: 11px
--radius-lg: 16px
--radius-full: 999px
```

## Формы

| Элемент | Форма |
|---|---|
| Кнопки `Button` | pill (`--radius-full`), высота 40 / 32 |
| Иконочные действия | круг, 32×32 |
| Поля и селекторы | скруглённый прямоугольник `--radius-md`, высота 40 |
| Чипы категорий | pill |
| Сегмент списка/сетки | общий прямоугольник `--radius-md`, высота 40 |
| Карточки и панели | `--radius-lg` |
| Профиль-бар | pill |

## Типографика

```text
Inter Variable
body: 15px / 1.5
tabs: 24px, активная — только цветом
заголовки: -0.018em
```

## Правила

- не смешивать круглые и квадратные кнопки в одной группе;
- иконка без текста — только круглая кнопка;
- группа иконок (список/сетка) — один сегмент с общей рамкой;
- главный CTA — плоская accent-кнопка, без градиентов и свечения;
- поля не делаем pill: pill только для кнопок и чипов;
- один размер контролов на экран: 40px, компактные — 32px.
