# Дизайн-система карточки

Статус: **0.7.x**. Это единственный контракт карточек записей и карточек ленты.

## Анатомия

```text
┌──────────────────────────────────────────────┐
│ [аватары] автор / люди   [оценка] [действия] │  header, 44px
├──────────┬───────────────────────────────────┤
│ постер   │ заголовок                [статус] │
│ 128px    │ подзаголовок                      │
│ 2:3      │ метаданные, рейтинг, рецензия     │
│          │ [дополнительные рецензии]         │
│          │                    [footer actions]│
└──────────┴───────────────────────────────────┘
```

- заголовок карточки — всегда внутри карточки;
- функциональная шапка — отдельная полоса с фоном `surface` и нижней границей;
- действия не перекрывают ссылку карточки;
- ссылка-оверлей никогда не должна получать stacking context выше действий.

## Размеры

| Токен | Значение | Где |
|---|---:|---|
| `--card-padding` | 12px | внутренние отступы |
| `--card-gap` | 16px | постер ↔ текст |
| `--card-radius` | 16px | скругление |
| `--card-poster-width` | 128px | постер list |
| `--card-poster-width-sm` | 76px | постер mobile |
| `--card-header-height` | 44px | шапка с автором |
| `--card-control-size` | 28px | иконки действий |
| `--card-grid-min` | 480px | min ширина колонки |
| `--card-grid-gap` | 12px | gap grid |

## Шапка

Слева: до трёх аватаров, имя/имена, при необходимости счётчик людей.
Справа: средняя оценка (если людей больше одного) и действия.

- высота шапки фиксирована 44px;
- имя в одну строку, `text-overflow: ellipsis`;
- шапка не растягивается от длины заголовка;
- действия: `лайк`, `добавить`, `не интересно`;
- иконки 28×28, `aria-label` и `title` обязательны.

## Режимы

### List

- постер 128px, текст справа;
- шапка над постером и текстом;
- footer действий прижат к низу карточки.

### Grid

- `repeat(auto-fill, minmax(480px, 1fr))`;
- gap 12px;
- карточки в ряду одинаковой высоты;
- постер, заголовок и шапка начинаются на одной линии;
- лишняя высота уходит в контент, а не в шапку.

### Mobile

- постер 76px;
- gap остаётся 16px;
- шапка переносится только если не хватает ширины;
- действия остаются в один ряд.

## Состояния

- hover — фон surface + акцентный border, без сдвига layout;
- focus-visible — 2px accent ring;
- buttons — accent fill on hover, `transform: scale(.97)` on active;
- disabled — opacity 0.55, без hover;
- reduced-motion — анимации отключены глобальным правилом.

## Варианты контента

- рекомендации: шапка показывает людей и среднюю;
- рецензии: 2 превью, остальные по кнопке;
- активность: шапка показывает автора;
- «Понравилось»: в шапке только «+»;
- community: количество людей и рецензий.

## Инварианты

1. Шапка всегда 44px и внутри карточки.
2. В grid все карточки ряда одной высоты.
3. Действия живут в шапке, не в отдельной строке под карточкой.
4. Одна карточка = одна ссылка-оверлей, кроме интерактивных зон.
5. Все размеры берутся из токенов, не из магических чисел.
6. Новые варианты карточек используют `FeedCardHeader` и `FeedItemActions`.
