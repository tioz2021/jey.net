# Тир-листы

## Полосы

Фиксированные: `S`, `A`, `B`, `C`, `D`, `E`, `F`.

## Авто-тир-листы

Для каждой категории создаётся один автоматический список. В него попадают
только записи с оценкой 1–10.

| Оценка | Тир |
|---|---|
| 10 | S |
| 9 | A |
| 7–8 | B |
| 5–6 | C |
| 3–4 | D |
| 2 | E |
| 1 | F |

При переносе записи между полосами авто-списка оценка меняется на верхнюю
границу тира:

| Тир | Новая оценка |
|---|---|
| S | 10 |
| A | 9 |
| B | 8 |
| C | 6 |
| D | 4 |
| E | 2 |
| F | 1 |

Перестановка внутри одной полосы оценку не меняет.

## Поведение

- новые и изменённые записи синхронизируются автоматически;
- записи без оценки в авто-список не попадают;
- авто-список создаётся при открытии «Тир-листов» или при добавлении оценки;
- существующие оценки бэкфиллятся миграцией `0071`;
- авто-список по умолчанию приватный, его можно опубликовать;
- авто-список нельзя удалить — удаление меняло бы саму автоматическую
  связь с оценками;
- запись нельзя убрать из авто-списка вручную: им управляет оценка;
- на мобильном тап по плитке открывает выбор тира;
- после смены оценки можно отменить действие в тосте;
- ручные тир-листы не меняют оценки записей.

## Публичная страница

```text
/u/{handle}/tier/{slug}
```

На публичной странице видны только публичные завершённые записи без
`public_hidden`.
