# PWA и офлайн-оболочка

## Установка

### Android / Chrome

1. Открой `https://j3ynet.site` в Chrome.
2. Меню → **Установить приложение** / **Добавить на главный экран**.
3. Запускай jey.net как отдельное приложение.

### iPhone / iPad

1. Открой сайт в Safari.
2. **Поделиться → На экран «Домой»**.
3. Запускай с иконки.

## Что кешируется

Service worker кеширует только оболочку:

```text
HTML-оболочка
/assets/ (JS/CSS)
/icons/
/media/ (обложки)
/manifest.webmanifest
offline.html
```

Ответы `/api/` и `/health` **никогда не кешируются**: это приватные данные.

## Офлайн

Если сеть пропала:

- открывается `offline.html` с кнопкой «Повторить»;
- ранее открытые обложки могут быть доступны из кеша;
- библиотека и API требуют сети.

Офлайн-библиотека есть только в desktop-клиенте. PWA — это
веб-оболочка, а не локальная база.

## Обновление

При новом релизе service worker скачивает новую оболочку, удаляет старый
кеш и активируется сам. Если обновление не подхватилось — закрой все
вкладки jey.net и открой сайт снова.

## Ограничения

- нет background sync;
- нет push-подписки по умолчанию;
- API-данные офлайн недоступны;
- в Tauri service worker не регистрируется.
