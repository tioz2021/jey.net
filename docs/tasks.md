## Как добавлять новые задачи

1. Взять следующий свободный ID `B31`, `B32`…
2. Добавить строку в «Дальше»: ID, задача, приоритет, оценка, зависимости.
3. При старте: перенести в «Сейчас», поставить `[~]`, дату и первую заметку.
4. При завершении: перенести в «Сделано», поставить `[x]`, дату, коммиты и
   одну строку «что получилось».
5. Любую проблему или решение фиксировать отдельным пунктом с датой. Старые
   комментарии не переписывать — это история.
