# Known limitations 0.3.x

## Item conflicts

Автоматические тесты и API-разрешение конфликтов готовы. Ручной сценарий
«два устройства одновременно редактируют одну запись» на двух физических
устройствах не прогонялся. Риск принят для 0.3.18: серверный merge,
conflict copy и экран разрешения в настройках проверены отдельно.

## Social conflicts

- Коллекции и комментарии сохраняют обе версии в `social_conflicts` и
  разрешаются в настройках.
- Профиль и лайки работают по правилу last-write-wins; conflict copy для них
  не создаётся.

## Server address

Desktop 0.3.x работает с `https://j3ynet.site`. Переключение адреса сервера
не входит в текущий объём.
