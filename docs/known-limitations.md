# Known limitations 0.7.x

## Item conflicts

Автоматические тесты и API-разрешение конфликтов готовы. Ручной сценарий
«два устройства одновременно редактируют одну запись» на двух физических
устройствах не прогонялся. Риск принят для 0.3.18: серверный merge,
conflict copy и экран разрешения в настройках проверены отдельно.

## Social conflicts

- Коллекции и комментарии сохраняют обе версии в `social_conflicts` и
  разрешаются в настройках.
- Профиль и лайки работают по правилу last-write-wins; conflict copy для них
  не создаётся.

## Chat E2E

- forward secrecy отсутствует: компрометация долгоживущего ключа раскрывает
  историю;
- сервер видит метаданные сообщений (участники, время, размер, реакции);
- поиск по encrypted-сообщениям только локальный и по загруженной истории;
- старые plaintext-сообщения не шифруются задним числом;
- recovery-фраза не хранится на сервере: потеря всех устройств и фразы
  означает потерю истории;
- desktop T150.5 хранит конверты, но release 0.6.0 требует проверки
  multi-device сценария на физических устройствах.

## Auto tier lists

- авто-списки создаются только для записей с оценкой 1–10;
- запись без оценки в авто-список не попадает;
- авто-список по умолчанию приватный;
- ручной порядок в авто-списке может быть пересчитан при смене оценки.

## Server address

Desktop 0.7.x работает с `https://j3ynet.site`. Переключение адреса сервера
не входит в текущий объём.
