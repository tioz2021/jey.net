# Локализация

Интерфейс и данные фильмов доступны на трёх языках: **ru**, **uk**, **en**.

## Определение языка

1. Cookie `jey_lang` (выбор пользователя).
2. `Accept-Language` браузера.
3. Русский, если язык не поддерживается.

Вошедший пользователь хранит выбор ещё и в профиле (`users.locale`).
Переключатель RU/UA/EN есть в шапке приложения, публичных и auth-страниц.
Смена языка обновляет cookie и профиль, затем вызывает `router.refresh()`.

Для ссылок, которые должны открываться на конкретном языке (SEO, письма),
поддерживается `?lang=ru|uk|en`: middleware ставит cookie до рендера, поэтому
страница сразу отдаётся на нужном языке. Канонический URL остаётся без query.

## Словари

- `frontend/lib/i18n/ru.ts` — базовый словарь; `uk.ts` и `en.ts` обязаны иметь
  те же ключи (`satisfies Record<keyof typeof ru, string>`).
- `frontend/lib/i18n/index.ts` — `translate`, `detectLocale`, `plural`,
  форматирование дат, чисел и денег.
- `frontend/lib/locale-context.tsx` — клиентский `useI18n`.
- `frontend/lib/i18n/server.ts` — `getServerLocale()` для серверных компонентов.

Проверка:

```bash
cd frontend
npm run check:i18n
```

Скрипт сравнивает наборы ключей и проверяет, что все статические вызовы
`t("...")` есть в словарях.

## Данные TMDB

Снимок фильма хранит `translations` для `ru`/`uk`/`en`: название, описание,
слоган, жанры, страны, языки, студии, режиссёра и роли. Название, режиссёр и
жанры-теги показываются по языку интерфейса; вручную переименованная запись,
свой режиссёр и свои теги остаются как введены. Общие факты (бюджет,
сборы, длительность, IMDb, рейтинг) не дублируются. Страница выбирает перевод
по locale, затем откатывается на `en`, `ru`, верхний уровень снимка. Старые
записи обновляются кнопкой «Обновить из TMDB».

## SEO

- `alternates.languages` указывает на `?lang=uk` и `?lang=en`.
- `sitemap.xml` содержит `xhtml:link` для трёх языков.
- `html lang` и локализованные `title`/`description` отдаются сервером.
- Юридические тексты: `frontend/lib/i18n/legal.ts`; нужна вычитка юристом.

## Как добавить язык

1. Добавить код в `SUPPORTED_LOCALES` и словарь.
2. Добавить ветку в `localeTag`, `detectLocale`, `language_from_tag`.
3. Добавить язык в `languageAlternates` и переключатель.
4. Прогнать `npm run check:i18n`, сборку и тесты.
