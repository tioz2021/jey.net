# 0.7.3

Дата: 23 ноября 2026.

Первый релиз с встроенным updater.

## Desktop

- `tauri-plugin-updater` и `tauri-plugin-process`;
- кнопка «Проверить обновления» → «Обновить»;
- скачивание и установка подписанного обновления;
- автоматический перезапуск после установки;
- подписанный Tauri `latest.json` с `platforms`;
- Windows остаётся unsigned (SmartScreen — известное ограничение).

## Инфраструктура

- подпись AppImage/EXE ключом updater;
- CI secret `TAURI_SIGNING_PRIVATE_KEY`;
- VPS-публикация отказывается выпускать релиз без `.sig`;
- Rust 1.90.

## Важно

0.7.2 не содержит updater, поэтому переход на 0.7.3 выполняется вручную.
Автообновление работает начиная с 0.7.3 → следующий релиз.
