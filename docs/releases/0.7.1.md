# 0.7.1

Дата: 22 ноября 2026.

Стабилизационный релиз после 0.7.0. Новых разделов нет — только качество,
офлайн-паритет, доступность и desktop.

## Web

- X11/XWayland режим для desktop; на Wayland + AMD прокрутка была медленной;
- кэш «Понравилось», тир-листов, ленты и «Сообщества»;
- offline `social_outbox` для тир-листов и лайков;
- stale-while-revalidate при смене фильтров;
- URL-фильтры ленты и рекомендаций;
- error/retry и пустые состояния без смешивания;
- доступность: skip-link, axe-тесты, мобильная матрица;
- i18n: plural, локализованные даты и числа;
- тесты компонентов и обновлённые E2E.

## Desktop

- X11 по умолчанию, настройка X11/Wayland;
- GPU-переключатель и FPS-диагностика;
- звук уведомлений вынесен из webview в системный плеер;
- VPS-канал обновлений с `latest.json` и SHA256;
- проверка обновлений в «О приложении».

## Инфраструктура

- quality gate с системными библиотеками Tauri;
- release pipeline: version gate, checksums, манифест, VPS-публикация;
- 0.7.1 tag и production deploy.

Известные ограничения — в [known-limitations.md](../known-limitations.md).
