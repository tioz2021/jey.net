# 0.7.4

Дата: 23 ноября 2026.

Релиз-проверка auto-update и стабилизация уведомлений.

## Уведомления

- один общий SSE stream на приложение;
- replay для поздно смонтировавшихся экранов;
- колокольчик, страница уведомлений и лента обновляются без reload;
- polling остаётся fallback.

## Desktop

- подписанный updater-манифест;
- кнопка «Обновить» скачивает и устанавливает новую версию;
- 0.7.3 → 0.7.4 — первый реальный auto-update.

## Инфраструктура

- `verify-release.sh` проверяет версию, файлы, подписи, SHA256 и health;
- release workflow запускает verify после VPS-публикации.
