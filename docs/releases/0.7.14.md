# 0.7.14 — первая полноценная стабильная версия

Дата: 26 ноября 2026.

Это parity-релиз после цикла стабилизации 0.10: web и desktop снова
собраны из одного тега, без новых пользовательских функций.

## Стабильность

- 100 активных пользователей проверены на VPS: p95 **77 ms**, 0 ошибок,
  CPU idle **84%**, PostgreSQL **12/30** соединений;
- `DB_POOL_MAX` ограничивает пул на процесс; preview получил отдельный
  маленький пул;
- client errors: retention 30 дней и алерт при >20 ошибках за 15 минут;
- healthcheck: p95, 5xx, backup, SSE, client errors;
- backup/restore drill и external preview проверены.

## Качество

- `shell.rs` разбит на 9 секций, `chat.rs` — на 5;
- 24 visual baselines, 19 functional E2E, desktop smoke 7/7;
- frontend coverage ratchet; Rust coverage — weekly/manual;
- bundle budget в CI; entry 175 KB gzip;
- route-level lazy loading, но `Items` и `Feed` оставлены eager, чтобы
  первый переход не деградировал.

## Web/Desktop parity

- один исходный код SPA;
- desktop собран из текущего тега, включая актуальный shell;
- подписанный updater-манифест;
- Windows installer остаётся unsigned: SmartScreen может предупредить.

## Ограничения

- один VPS и один PostgreSQL;
- E2E-чат без forward secrecy;
- нет HA и автоматического переключения при отказе VPS;
- письма требуют внешнего SMTP.
