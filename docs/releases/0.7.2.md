# 0.7.2

Дата: 22 ноября 2026.

Патч-релиз после 0.7.1: форма записи, realtime-уведомления и desktop-корзина.

## Форма записи

- черновик всей формы сохраняется в localStorage;
- после закрытия/перезапуска восстанавливаются поля, рецензия, постер и обложка;
- постер выбранного фильма сохраняется в черновике;
- обложка использует стабильный серверный `preview_url`;
- статус виден сразу, без «Дополнительных настроек»;
- при наведении на звезду показывается её оценка;
- кнопка «Назад» — в верхней панели слева;
- кнопка «Очистить» — отдельно справа, с подтверждением.

## Уведомления

- SSE-канал `/api/v1/notifications/stream`;
- колокольчик, страница уведомлений и лента получают live-сигнал;
- polling остаётся fallback;
- E2E: уведомление появляется без reload.

## Desktop

- корзина теперь читает локальные deleted-записи, а не активные;
- удаление навсегда и очистка корзины работают локально;
- звук уведомлений вынесен из webview;
- X11-режим и GPU-настройка сохранены.

## VPS

- `latest.json` содержит Linux и Windows артефакты;
- страница `/download` показывает `.exe`;
- обновление в приложении проверяется вручную.

Известные ограничения — в [known-limitations.md](../known-limitations.md).
