# Changelog

## [0.1.0] — 2026-11-02

Первая рабочая версия веб-портала. Десктоп и синхронизация — в 0.2.0 (M8).

### Добавлено

- **Аккаунты:** регистрация, вход, выход, смена пароля, сброс пароля,
  подтверждение email, удаление аккаунта с обезличиванием, аватар,
  отзыв всех сессий, ограниченный rate limit на вход и регистрацию.
- **Записи:** четыре типа (фильм, книга, картинка, другое), статусы,
  оценки, заметки, ссылки, теги, мягкое удаление в корзину и восстановление.
- **Поиск и список:** триграммный поиск, фильтры по типу, статусу, году,
  оценке и тегу, шесть сортировок, курсорная пагинация.
- **Статистика:** сводка, разбивка по типам/статусам, средняя оценка,
  распределение по годам и месяцам.
- **Медиа:** загрузка JPEG/PNG/WebP до 10 МБ, обложки и аватары,
  WebP-рендиции, квота 200 МБ, сборка осиротевших файлов.
- **Экспорт и импорт:** JSON и CSV; импорт идемпотентен по `id`.
- **Публичный профиль:** opt-in, только завершённые записи, без заметок
  и email, попадает в `sitemap.xml`.
- **Веб-интерфейс:** вход/регистрация, каталог с фильтрами, карточка записи,
  редактор, теги, статистика, настройки, экспорт, тёмная тема.
- **Лендинг** с реальными скриншотами, политика конфиденциальности и условия.
- **SEO:** заголовки, Open Graph, canonical, `robots.txt`, `sitemap.xml`.
- **Прод:** VPS с Ubuntu 24.04, PostgreSQL 18, systemd-юниты, Caddy с
  автоматическим TLS, firewall, swap, автообновления.
- **Мониторинг:** health-check каждые 5 минут с алертами при смене состояния,
  ограничение роста журналов.
- **Деплой:** `scripts/deploy.sh` — сборка, миграции, health-check и
  автоматический откат; ручной workflow в GitHub Actions.
- **Документация:** OpenAPI 3.1, руководство по API, runbook, аудит
  безопасности, нагрузочные тесты, схема деплоя.

### Изменено

- Статика и `public/` включены в standalone-сборку Next.js — без этого
  скриншоты лендинга не доезжали до сервера.
- `robots.txt` генерируется на лету, а не запекается с `localhost`.
- Обложки декодируются асинхронно, ленивая загрузка в списках.

### Безопасность

- Добавлены CSP, `Permissions-Policy`, COOP; убран `X-Powered-By`.
- Закрыт отладочный полигон `/dev` на проде.
- `postcss` обновлён через `overrides` (закрыты advisories Next.js).
- `ctutils` обновлён до 0.4.4 (RUSTSEC-2026-0385, неконстантное сравнение).

### Известные ограничения

- SMTP не настроен: письма пишутся файлами на сервере и не доходят.
- Резервные копии не делаются (T77 отложена).
- Один сервер, без репликации и CDN.
- Десктоп и синхронизация появятся в 0.2.0.
